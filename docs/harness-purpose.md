# 하네스 목적 (R2)

> 판정 기준: `story-service.md` (R1-A) / 작업 흐름 재료: `story-work.md` (R1-B). 둘은 섞지 않는다.

## 매번 달라지는 것 (입력)
- 대상 유저스토리 번호 1개 (1~5, `story-service.md` 기준)
- 고정 입력: `prd.md`, `design.md`, `story-service.md`

## 사용자
- 실행: 본인 1명
- 결과물 수신: 내부 관계자 (story-work 5단계)

## 범위
- 포함: story-work 1~4단계 + 7단계(가이드 검토)
- 사람 몫: 5단계(내부 관계자 협의)
- 제외: 6단계(토큰·컴포넌트 전체 제작)

## 완료 기준
선택한 유저스토리 1개에 대해 390×844 Figma 키스크린 2~3개가 있고,
design.md 위반 0건, 어기면 안 되는 것 A·B 위반 0건이며, 사람 승인 1회를 받았다.
